まずは、この3ステップ

GET STARTED
01

参加者を選ぶ

2〜60人で対戦。名前を読点・カンマ・改行で区切るか、名鑑やランダムボタンから選択。最初は「ランダム5人」で能力を見比べると分かりやすい。

02

能力を確認して予想

参加者を選ぶと能力とHP・攻撃力・移動速度を確認できます。回復、拘束、範囲攻撃など、何で生き残るキャラかに注目。

03

観戦して振り返る

「バトル開始」で自動戦闘。見逃したくないときは0.5倍速や一時停止。終了後は撃破数・与ダメージと戦闘記録を見比べよう。

試合のルール

最後に生き残った参加者が勝者。召喚された支援者は参加者の人数に含みません。

参加人数モード会場・表示観戦のポイント
2〜5人少人数狭い会場 / キャラ2倍表示個々の能力や対面の相性を追いやすい。
6〜20人中人数中くらいの会場 / キャラ1.5倍表示範囲攻撃、召喚、横からの攻撃を観察。
21〜60人通常広い会場 / 通常表示序盤の位置関係と、生存者が減った後の展開に注目。
50秒が分かれ目。サドンデスありでは、試合内時間50秒で攻撃力10倍・移動速度3倍。回復で粘れていても一気に倒される可能性があります。サドンデスなしでも180秒で試合終了。複数人が残れば時間切れです。

会場は時間経過と生存者数に応じて縮小。生存者が減っても、開始時に決まった人数モードは変わりません。再生速度を上げると観戦が速く進みますが、キャラのステータスは変わりません。

ステータスの見方

ATK / 攻撃力

能力の火力にも関わる

接触攻撃と多くの攻撃能力の威力の基準。能力ごとに倍率や発動間隔が異なるため、ATKだけで実際の火力は決まりません。

HP / 最大体力

回復・盾との組み合わせ

倒されるまでの余裕。一部の回復・盾・召喚の耐久は最大HPに比例するため、同じHPでも能力次第で粘り方が変わります。

SPD / 移動速度

接近と位置の変化が速い

移動が速くなり、接触や能力の有効範囲へ入る機会が変わります。回避率・弾速・クールタイムが直接上がる効果はありません。敵への接触が増える可能性もあります。

Gradeは名鑑の設定。数値や能力は個別に設定されています。Gradeが高いだけで全ての相手に必ず勝てるわけではありません。

注目したい能力と相性

MATCHUP NOTES

以下は現在の能力処理から読める特徴と観戦の目安。勝率ランキングではありません。配置・相手・人数で結果は変わります。

イトグチ / 防御への回答

無敵・盾・回避を崩す

3.2秒間隔で盾を消し、一部の強化状態を解除。能力を1.6秒封じ、攻撃力7倍の消去攻撃を与えます。消去攻撃は通常の回避や防御軽減を通らないため、守りに依存する相手に注目。

エンプレス / 撃破で成長

最初の撃破が流れを変える

開始時からオリハ・トリエ・ミルク・ユージの能力を持ち、追加能力の倍率は0.65。自分で倒した本体の能力を重複なく獲得し、最大HPの12%を回復します。召喚物を倒しても能力獲得の対象にはなりません。

X・アシャラ・オジョー / 複数への圧力

密集で攻撃の価値が変わる

Xは周囲への炎・氷を交互に使用。アシャラは追尾する雷撃が近くの別の敵へ連鎖し、オジョーは追尾弾の爆風で周囲も攻撃。人数だけでなく、攻撃時に敵が集まっているかが大切です。

クラリーヌ / 拘束と追撃

石化は相手を硬くもする

石化中は1.5秒停止し、通常の被ダメージは0.6倍。ただし石化させた本人からは1.3倍。自分の追撃には好都合でも、周囲の攻撃から相手を守る場面があります。

タナカ・ミルク・ソイ / 生存力

回復と致命傷は別の問題

タナカはHP55%未満で全回復し、状態異常も解除（10秒間隔）。ミルクは3秒間隔で自身の最大HP9%を回復。ソイは致命傷から一度だけ全回復。タナカやミルクは回復前に倒されると間に合いません。

デビル・ベイン・ミュー / 支援者

支援の種類で相性が違う

デビルは機械弾を無効化し、近い敵の砲台を掌握。ゴーレムやダイヤ兵は機械ではありません。支援者は本体の脱落で停止するため、数が多くても本体の耐久が重要です。

隠れる能力にも相手を選ぶ。ルサイやドンは狙われにくくなりますが、ホオズキ・ツキチヨ・ワンは隠れた相手を捕捉できます。隠れていても近距離では狙われ、全ての攻撃を避けられるわけではありません。

名前・本名・能力・所属で検索。ここに表示するのは標準設定です。ゲーム内で保存した編集値は反映しません。

試合を比較するコツ

  1. 同じ条件を揃える。参加者・入力順・試合シード・サドンデス設定・編集値が同じなら同じ試合を再現できます。
  2. 一度に変えるのは1項目。能力の違いを見るなら、自由入力のキャラを同じATK・HP・SPDに編集し、能力だけ変えて比較。
  3. 複数のシードで確かめる。一試合の勝者だけで強さを決めず、相手や初期配置を変えて観察。人数が変わると会場サイズも変わります。
  4. 勝利以外も見る。撃破数・与ダメージ・脱落時刻を一緒に確認。最後まで残る力と、敵を倒す力は異なります。

例：プラス・ユージ・ランス・コンケの4人で少人数戦 → 生徒会の対戦 → Grade別ランダム5人。同じGrade内で能力の働き方を比べるのもおすすめです。

よくある質問

全員を同じ能力で戦わせたい

試合前の「全員の能力を揃える」で能力を選び、「全員に適用」を押してください。攻撃力・HP・スピードは各キャラのままです。参加者の入れ替えや再試合にも適用され、「解除」または再読み込みで各キャラの能力に戻ります。個別に保存した能力や数値は消えません。

ランダム選択でエンプレスが出ないのはなぜ？

ランダム20人・60人・5人・Grade別・名鑑の「表示中から20人選ぶ」ではエンプレスを除外しています。名前の入力や名鑑での手動選択では参加可能。「生徒会全員」にはエンプレスも含まれます。

「生徒会全員」にミルクは含まれる？

現在のボタンはミルクを除外し、立場に生徒会長・生徒会副会長・生徒会役員があるキャラを選びます。ミルクを含めたいときは手動で追加できます。

知らない名前を入力するとどうなる？

自由入力として参加します。標準の基礎値は攻撃力18・HP1250・移動速度5.5。名前に応じた固定能力が割り当てられ、同じ名前なら相手や入力順によらず同じ能力になります。

8倍速にすると結果も変わる？

再生速度は戦闘の進む速さを変える設定です。同じ参加者・入力順・試合シード・サドンデス・編集値・共通能力設定なら、再生速度を変えても同じ戦闘を再現できます。

ステータスを編集したのに試合中の数値が変わらない

保存した編集値は次の試合から適用されます。個別の「この名前の編集を戻す」、または画面下の「編集したステータスをリセット」で標準設定へ戻せます。

絶対に勝つ組み合わせや、最新の勝率はある？

このページには条件の異なる試合を混ぜた勝率や固定の最強ランキングを載せていません。参加者・人数・サドンデスなどの条件を決め、複数試合で比較すると、その条件での得意不得意を確かめられます。
