# 生徒会戦のイトグチ強化（2026-10-06）

目標は、現在の「生徒会全員」プリセットからエンプレスを外した試合で、イトグチの勝率を約30%にすること。ユーザーの指定に従い、イトグチ自身を強化しました。

## 変更

イトグチの基礎ATKのみ **60 → 85**（約41.7%増）。接触攻撃と消滅攻撃が強くなります。消滅攻撃はATK×7なので、通常時の基本ダメージは420→595です。HP 2800、SPD 7.2、消滅の再使用3.2秒・能力封印1.6秒、他のキャラのデータ、エンジンは変更していません。参加者に応じた勝率補正や勝者の抽選はありません。この基礎ATK変更は他の組み合わせの試合にも適用されます。手動編集したATKが保存されている場合はそちらが優先されます。

## 検証条件

- 公開版と同じ1/60秒刻み、11人の中人数モード（半径250）。編集値なし（比較用にイトグチのATKだけ指定）。
- 参加者の順序：アシャラ、ベレー、クラリーヌ、イトグチ、ジャッジ、ミュー、セレナ、タナカ、タイタン、ツキチヨ、X。
- プリセットが元から除外しているミルク、カガチ、デビルは参加しません。エンプレスも参加しません。
- 勝率の分母は全試合。引き分け・時間切れも分母に含みます。初期配置・移動・回避等の乱数を試合ごとに変更。
- 初期の探索は `ito-tune:0`〜でATK70/80/90を400試合ずつ比較し、24.5%/29.75%/32.75%。別シード1,000試合でATK80は27.2%だったため、85へ調整。

| 条件 | ATK | 試合数 | イトグチ勝利 | 勝率 | 95% Wilson区間 |
|---|---:|---:|---:|---:|---|
| 変更前・サドンデスあり | 60 | 1,000 | 187 | 18.7% | 16.4〜21.2% |
| 変更後・サドンデスあり | 85 | 1,000 | 301 | 30.1% | 27.3〜33.0% |
| 別シードで最終確認・サドンデスあり | 85 | 1,000 | 315 | 31.5% | 28.7〜34.4% |
| 変更後・サドンデスなし | 85 | 500 | 171 | 34.2% | 30.2〜38.5% |

変更後のサドンデスあり2,000試合を合算すると **616勝 / 2,000試合 = 30.8%**。一定の勝率を保証する仕組みではなく、人数・参加者・参加者順・編集・サドンデス設定によって結果は変わります。

## 再現

```sh
node scripts/simulate-itoguchi.cjs 1000 60 itoguchi-validation-v1
node scripts/simulate-itoguchi.cjs 1000 85 itoguchi-validation-v1
node scripts/simulate-itoguchi.cjs 1000 85 itoguchi-final-v1
node scripts/simulate-itoguchi.cjs 500 85 itoguchi-off-v1 off
npm test
npm run test:ui
```

集計は `before.json` / `after.json` / `confirmation.json` / `sudden-death-off.json`。変更前・変更後の比較には同じシード列を使用し、最終確認には別のシード列を使用しました。既存のGrade 5調整の履歴フィクスチャはそのまま保存し、範囲検証に今回のイトグチATKのみの変更を明示的に追加しました。全キャラ・別名・能力・60人試合・シード再現・エフェクト上限と、UIのプリセット・編集・倍速・再試合テストは通過しています。
