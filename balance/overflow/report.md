# オーバーフロー能力（2026-10-06）

生存している本体が5人以下、HPが最大HPの20%以下の両条件を満たすと自動発動。各本体につき1試合1回です。分身と支援者は人数に数えず発動もしません。ダメージで条件を満たした時と毎フレームで確認します。致命傷後の復活ではなく、生存中だけ発動します。封印中は保留し、解除後に条件を満たせば発動。発動の前に使用済みを記録するため、反撃や連鎖でも重複しません。次の試合でリセットします。

選択中のメイン能力に付属します。個別の能力変更・全員共通能力・自由入力に割り当てられた対応能力でも同じルールです。エンプレスの吸収で追加された能力から究極技を別途発動することはありません。ダメージは現在のATKで計算し、サドンデスの強化も反映します。

## 検証

- 条件境界：6→5人、20%ちょうど、20%より上、致命傷、死者、分身、封印の解除。
- 1回制限：回復後・時間経過後も再発動しないことと、新しいWorldでのリセット。
- 13種の効果：凍結・継続熱、追尾雷の標的、盾・支援者、爆風、確定会心・回避、暗転、質量の引き寄せ/押し出し、無敵終了、判決、全回復・吸収終了、分身上限・既存分身の強化と本体脱落。
- UI：待機/使用済み、能力変更時の説明、検索13件、ハッタン+、25人参加、長押し・スクロール取消・60人上限、8倍速・ランキング。
- 通常93人のデータは既存範囲テストで一致を確認。
