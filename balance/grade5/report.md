## 能力の主な調整

- タナカ: 通常回復と致死時復活が別々に使えた構造を修正。HP55%未満で全快、再使用10秒。HP0からの復活は廃止。
- セレナ: 回復を最大HPの10% / 4.5秒へ。ミュー: ダイヤ兵1体、兵の耐久・攻撃倍率を抑制。
- タイタン: 回避率24%。グモン: 無敵1.7秒 / 6秒。
- X・アシャラ・オジョー: 主力攻撃の倍率、範囲、再使用間隔を調整。
- クラリーヌ: 自分が石化した相手への攻撃倍率を追加。他者の石化対象への軽減は維持。
- ツキチヨ・ヤオイ・マイナス: 近接・範囲攻撃を補強。
- ミカエル: 門で近くの相手へ移動し攻撃、一時防御。デビル: 会場に用意された機械砲台を運用。
- ジャッジ・ベレー・カガチ・パスター・ダンチョー: 基礎ATKとHPで調整。

## 再現方法

基準旧版コミット: `ed32441d77d3d2cc5196fa10a0a73649720e07a8`。`before-holdout.json` / `after-holdout.json` が同じシードでの比較、`before-mixed.json` / `after-mixed.json` が混合対戦の記録です。全記録でユーザー編集値は使用していません。

```sh
node scripts/simulate-grade5.cjs --mode group --matches 2000 --prefix grade5-final-holdout-v2 --out after-holdout.json
node scripts/simulate-grade5.cjs --mode mixed --matches 1500 --prefix grade5-final-mixed-v2 --out after-mixed.json
```

旧版を別の作業ディレクトリにチェックアウトし、現行スクリプトへ `--engine /旧版の絶対パス/engine.js` を渡すと、同じ2,000試合を旧版で実行できます。参加者順と試合用乱数はそれぞれ固定シードで生成し、処理は60fps。表示用イベント・エフェクトだけ抑制しています。

画面には指定19人の「Grade 5対戦」プリセットを追加。以前にステータスを編集した場合は、画面の「編集したステータスをリセット」で更新された初期値を適用してください。
