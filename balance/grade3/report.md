# Grade 3 勝率分散の調整（2026-10-06）

Grade 3全19人戦とランダム5人戦で勝利が分散するようにATK・HPを調整しました。能力処理・再使用間隔・SPDと、他Gradeの74人は変更していません。盾・復活などによる実効耐久も考慮しています。変更した初期値は混合Gradeの試合にも適用され、保存された手動編集値があればそちらが優先されます。勝者の抽選や勝率に応じた試合中の補正は行っていません。

## 条件

- 公開エンジンと同じ1/60秒刻み、サドンデスあり、初期能力・初期ステータス。
- 全員戦は中人数モード（半径250）、5人戦は少人数モード（半径185）。
- 参加者順は毎回シャッフル。5人戦は19人から重複なく抽出。抽出と戦闘に別々のシードを使用します。
- 全員戦は全試合、5人戦は各キャラが参加した試合が分母です。引き分け・時間切れも分母に含みます。
- 変更前は全員戦500試合、5人戦1100試合（grade3-validation-v1）。親コミットは140bdcc2b2c84021d4574bc7e28a33d5b8a354f0。
- 探索用シードgrade3-tune-v1〜v5と別のgrade3-final-v2で最終確認：全員戦1000試合、5人戦1800試合。
- 原作の序列ではなくゲーム内の調整です。相性・人数による差は残り、サドンデスなしや他Gradeとの混合戦はこの集計の範囲外です。
