# カス校バトルロワイヤル

[ginghum/battle](https://github.com/ginghum/battle) の円形フィールド、接触戦闘、縮小、倍速の操作を引き継いだカス校専用シミュレーターです。[カス校名鑑](https://ginghum.github.io/START/)の93人の能力を、新しい戦闘エンジンに個別実装しました。

## 遊び方

1. 2〜60人をカンマ・読点・改行で入力。
2. 「バトル開始」で最後の一人まで戦闘。終了画面で参加者のキル数トップ5を表示します（5人未満なら全員、同数は同順位、表示は最大5人）。脱落者も対象、召喚物は対象外。引き分け・時間切れでも表示します。生き残りランキングも最大5人表示し、生存者が上位、脱落者は脱落時刻が遅い順です。同時脱落・時間切れの生存者同士は同順位。名前・顔アイコン・生存時間を表示します。
3. 参加者を選ぶと能力の説明・ステータスを確認できます。編集は次の試合から適用されます。

ニックネーム・本名のどちらでも固定の能力と基礎値になります。X／Ｘ／エックスにも対応。名鑑にない名前は、名前から93種類のカス校能力のいずれかを固定割り当てし、基礎値は全員 **ATK 18 / HP 1250 / SPD 5.5** です。参加者の組み合わせや順番によって自由入力の能力は変わりません。

「ランダム20人」「ランダム60人」「ランダム5人」「ランダム2人」、検索できる名鑑選択があります。Grade 1〜5それぞれからランダムに5人を選ぶボタンも用意しています。各Gradeの全員参加ボタンも用意し、エンプレスを除いて選択します（Grade 1:27人 / 2:9人 / 3:19人 / 4:15人 / 5:25人（最終モード4種を含む））。すべてのランダム選択はエンプレスを候補から外します。0.5〜8倍速・一時停止・中断・再試合に対応。同じ参加者順・試合シード・編集値・サドンデス・共通能力設定なら同じ結果を再現します。「全員の能力を揃える」で能力を選び「全員に適用」を押すと、そのページ内で全参加者の能力だけを一時的に統一します。参加者の変更や再試合にも適用され、攻撃力・HP・SPDと個別の保存値は維持。「解除」か再読み込みで元の能力（個別編集があればその能力）へ戻ります。共通設定中は個別の能力変更を無効にし、数値だけ編集できます。空欄のシードは毎回ランダムで生成し、戦闘記録欄に表示します。Spaceで一時停止。タブが隠れると自動で一時停止します。

## 設定とゲームへの翻訳

- 参照は START の `characters-data/*/profile.json`、2026-10-05時点の93人。ニックネーム、本名、Grade、所属、身長、能力を参照しました。元データのコミットと各ファイルのSHAは `source-snapshot.json` に記録しています。
- **戦闘数値は公式設定ではなく推定値**。Grade・体格を基準に、イトグチ、エンプレス、マイナス、タイタンなどの記述された実力、低Gradeでも決闘の強いランスなどを個別補正しました。
- 能力は元の汎用スキルの名前変更ではなく、専用の効果・持続時間・条件を実装しています。同じ質量操作でもプラスは構えの切り替え、マイナスは広い対象制御と重量攻撃に分けています。
- エンプレスは開始時に捕食と、その試合に参加していないキャラ10人の能力をランダムに持ちます。通常版・+版も候補に含み、参加キャラの通常版・+版は両方除外。同じキャラの通常版と+版を重複して選びません。同じ試合シードで同じ初期能力に。能力の初期倍率は従来の0.65を維持します。開始能力をログ・参加者のツールチップ・詳細に表示。自分が倒した本体から能力を獲得し、重複しません。獲得時の攻撃規模はコピー元から固定し、その後コピー元が変わっても追従しません。原作の膨大な全能力を網羅したものではありません。
- ミューはダイヤ兵を最大1体作り、ダイヤの盾と結晶弾も扱います。
- タナカはHP55%未満で自身を健康な普通の状態へ戻します。再使用10秒。HP0からは復活しません。相手の能力を無効化する能力にはしていません。
- オーガは他者だけを強化します。個人戦で味方がいない場合は肉体で戦います。自身の能力強化はしません。
- モルペウスの能力は眠っている相手にだけ有効です。全員共通のゲームルールとして、HP25%未満で12秒ごとに1.2秒休息し、その時に夢を長引かせます。覚醒中の敵を能力だけで眠らせません。
- ツクリは会場に用意された補給箱を開けて防具を調達します。拘束全般を「解錠」で解除しません。ベル・ロマンチ・ダンカチも、準備した材料や道具を使う想定です。物を無条件に生成する能力にはしていません。
- 非戦闘能力は索敵、偽装、道具の運用などへ翻訳。ゲームの具体的効果は各参加者の詳細に表示します。性格による味方扱いや固有の人間関係は戦闘ロジックに入れていません。
- 開始人数に応じて自動で会場と表示サイズを調整。5人以下は少人数モード（半径185、2倍表示）、6〜20人は中人数モード（半径250、1.5倍表示）、21人以上は通常モード（半径385、等倍表示）。キャラ・弾・範囲・エフェクト・名前をまとめて拡大します。途中の脱落による切り替えはありません。戦闘上の当たり判定やキャラの数値は拡大しません。
- サドンデスは試合前にオン・オフ設定可能（初期値オン、保存対象）。オンでは50秒で攻撃10倍・移動3倍。180秒で決着しなければ「決着なし」。全員脱落は引き分け。回復・無敵には有限の再使用間隔を設けています。

SPDによる回避ボーナスはSPD×0.5%（上限5%）。能力の回避率に加算し、合計上限65%です。能力封じでもSPD分は有効。ダッシュ・サドンデスの移動倍率では増えず、消去攻撃は回避できません。

## ファイルと実行

静的HTML / CSS / JavaScriptのみ。ビルド・外部UIライブラリ・バックエンドは不要です。キャラの顔アイコンはユーザー提供の手描き一覧画像を参照します。元画像は `assets/character-sheet.jpg` に保存し、`icons.js` の顔領域と輪郭クリップで名前の文字を除いて表示します。ジャッジとジェンドは共通の顔です。参加者一覧・名鑑・戦闘・勝者表示で使用。画像が読み込めなくても戦闘は動きます。

```sh
python -m http.server 8000
# http://localhost:8000 を開く
node tests/engine.cjs
npm install
npm run test:ui
```

- `data.js`: 全93人・別名・基礎数値・能力説明
- `engine.js`: 固定60fpsの戦闘計算。Nodeでも実行可能
- `app.js`: 入力・描画・編集・名鑑選択・保存
- `icons.js`: 全93キャラの顔の表示領域・輪郭クリップ
- `style.css` / `index.html`: レスポンシブ画面
- `tests/engine.cjs`: 全キャラ／別名、固有効果、60人、シード再現、エフェクト上限
- `tests/ui.cjs`: jsdomで入力、検索、編集、上限、一時停止、8倍速、再試合を検証

Canvas内のエフェクトはシミュレーション時間で消え、件数も制限します。終了時にエフェクト・弾・ゾーンを消去。召喚者の脱落で支援者は停止し、死亡した召喚のデータも毎フレーム除去します。画面の倍速を変えても戦闘計算の刻み幅は変えません。

## 最終モード

`プラス+`・`ヒカル+`・`コバル+`・`ハッタン+`（全角の`＋`、本名＋にも対応）で、ゲーム用のGrade 5最終モードに変化します。通常版との同時参加が可能です。名鑑の選択画面・攻略ページにも4種を掲載し、編集と全員共通能力にも対応。通常93人のデータ・自由入力の能力割当は維持しています。Grade 5のランダム5人にも最終モード4種が登場し、他のランダム人数ボタンは通常版から選びます。生徒会全員ボタンは削除しました。Grade 5全員には最終モード4種を加え、エンプレスを除く25人が参加します。名鑑では通常93枚のカードを表示し、プラス・ヒカル・コバル・ハッタンを600ms長押しすると+版へ切り替えて選択します。選択済みの通常版は+版に置換。再度長押しすると通常版に戻ります。スクロールや指を離す操作で未成立の長押しを取り消し、長押し後のクリックによる誤解除を防ぎます。Shift+Enterでも切り替え可能です。最終モード名の検索・直接入力も使えます。顔画像は通常版を使用します。

- プラス+：ATK 47.2 / HP 2732 / SPD 6.4。2.4秒ごとに軽量化と重量化を交互に使い、重量化で強化・防御と近距離の衝撃波。
- ヒカル+：ATK 52.9 / HP 2760 / SPD 6.2。2.7秒ごとに対象の盾を85%削り、4本の貫通刃を放つ。
- ハッタン+：ATK 48 / HP 2818 / SPD 6.2。3.5秒ごとに強化分身を最大4体作成。
- コバル+：ATK 44.7 / HP 2525 / SPD 6。3.8秒間隔で1秒チャージ、次の接触を8倍に強化。チャージを使うまで再チャージせず、チャージ中は軽い防御。

実装・強さの検証は `tests/final-modes.cjs` と `balance/final-modes/report.md`、再現は `npm run simulate:final-modes -- 1200 five final-modes-validation-v1`（全員戦は `500 all`）。最終モードはシミュレーター内の設定で、START名鑑の原作Gradeは変更していません。

## Grade 5全員戦の均等化（2026-10-06）

エンプレス・イトグチを除く24人（ジェンドと最終モード4種を含む）は各約4.17%、イトグチを加えた25人ではイトグチ約40%・残り24人が各約2.5%を目標に調整しました。Grade 5の24人とイトグチのATK・HPを個別調整し、SPDとエンプレス・他Gradeのプロフィールは維持。ミューの盾は最大HPの12%→11%、クラリーヌの石化・拘束は1.5秒→1秒。能力の種類・発動間隔は維持しています。同じ能力を使う自由入力・コピー能力にも効果の変更を適用します。過去の勝率資料は各時点の記録で、最新の数値・結果は `balance/grade5-equal/report.md` を参照してください。

標準ステータス・個別編集なし・能力統一なし・サドンデスあり・全員参加の条件で確認。再現は `npm run simulate:grade5-equal -- 4000 equal-validation-20261006-v2`。固定60fpsの戦闘を最後まで計算し、その結果から勝率を集計します。索敵を安定ソートから最短距離の走査へ変え、受動能力の不要な索敵を省略。変更前と同じ試合結果・ユニット状態・RNGを確認し、シミュレーションを高速化しました。

最終確認（別シード・各4,000試合）では、24人戦は3.55〜5.00%。イトグチ入りはイトグチ40.88%、他24人1.88〜2.95%。詳細は上記レポートを参照してください。

## エンプレスの初期能力変更（2026-10-06）

固定の追加能力4種を、非参加キャラ10人からのランダム能力へ変更しました。捕食による追加獲得・撃破時の回復・ATK 62 / HP 1600 / SPD 6.5は維持。自由入力や能力編集で捕食を使う場合にも適用します。同じ試合で捕食を使う参加者には同じ初期能力10個を与え、全員共通能力でも揃います。獲得後の能力は各自で保持します。非参加の判定は参加者の名鑑上のキャラで行い、本名・別名・全角表記も認識。開始前は入力済みシードで仮抽選し、シード未指定なら試合開始時に改めて抽選します。過去のエンプレス勝率は固定初期能力の時点の記録です。
